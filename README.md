# OOCL SAP Copilot Configuration

## Overview

This repository contains GitHub Copilot configuration and guidance for SAP
ABAP work.

It is created by **OOCL MNLSAP** and is intended for use by **OOCLSAP only**.

The repository includes:

- ABAP FS workspace safety and operating rules
- Copilot agents for guided SAP ABAP tasks
- Reusable skills, prompts, and instructions
- Supporting documentation for the configured workflows

## Usage

Use this repository only in the approved OOCLSAP environment. Follow the
workspace rules in [AGENTS.md](AGENTS.md) before working with ABAP objects.
